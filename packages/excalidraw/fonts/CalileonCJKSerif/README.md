## Replacing the web derivative with the original

Download the upstream original linked above. In a host application, register it as a `FontFace` under the CSS alias `Calileon CJK Serif`, using the original TTF file, instead of these web subsets. Glyph data is otherwise unchanged. For the first released IPA font, see [IPA fonts](https://moji.or.jp/ipafont/).
